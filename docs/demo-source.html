01

MODEL

Kimi K3 打到前排

官方发布 + 外媒跟进

月之暗面放出旗舰 Kimi K3：2.8 万亿参数、100 万 Tokens 上下文，主攻长程 coding、端到端知识工作与深度推理。

图示：参数 / 上下文 / WebDev 分数 / 定价

· 技术：Kimi Delta Attention + 注意力残差，原生视觉
· API：kimi-k3，工具调用 / 结构化输出 / 上下文缓存
· 定价：百万 Tokens 输入缓存命中 2 元 / 未命中 20 元，输出 100 元
· Arena WebDev：1679，高于 Claude Fable 5 的 1631

开源不再只是追赶策略，它开始变成价格与生态的武器。

来源：Kimi 官方 / Reuters / Axios · 证据等级：已官宣

02

GOVERN

WAIC：治理升到最高规格

官方通稿 · 主流媒体

上海 2026 世界人工智能大会 开幕，主轴不是又一个产品展，而是全球 AI 治理。外媒标题反复出现的意思是：AI 不应是单国独角戏；中国愿做发展中世界的 AI 合作伙伴；同时提醒风险与安全过度扩张。

图示：舞台 / 主轴 / 政策工具 / 行业含义

同步出现：国家发改委侧 《人工智能合作发展行动计划》 发布、大会主席声明，以及多场前沿安全风险协同治理讨论。

行业含义：规则讨论正式进入国家间议程；企业侧关键词会更像跨境能力、安全标准、发展中市场入口。

来源：新华社等通稿 / CNBC / NPR · 证据等级：官方通稿

03

REALTIME

Wan-Streamer：视频电话 550ms

阿里通义 · 官方介绍

阿里通义发布 Wan-Streamer v0.2：端到端全模态理解与生成，把听、看、说、演塞进单个 Transformer。端到端响应约 550ms（模型约 200ms + 网络约 350ms），分辨率提到 640×368 @ 25FPS。

Agent 之后，下一场入口争夺可能发生在实时通话与视频交互里。

来源：IT之家转述官方介绍 · 2026-07-17

04

BODY

具身智能同一天三记重锤

2028 预测 · 小米基座 · Thor 扩军

图示：Streamer 延迟指标 + 具身三记重锤

A银河通用王鹤：具身 ChatGPT 时刻有望 2028 年底前；未专项训练任务成功率目标 70%–80%。（产业判断）

B小米 Robotics-1：超 10 万小时真实轨迹预训练；代码与权重计划近期全面开源。

CNVIDIA Jetson Thor 扩容 T3000 / T2000，边缘机器人算力分层，预计 2027 Q1 上市。

证据边界：2028 是产业判断，不是承诺；小米开源节奏以官方最终发布为准。

05

CONTRAST

对照：延期 vs 开源

Gemini 3.5 Pro · Grok Build

Gemini 3.5 Pro 延期（Bloomberg / 9to5Google）：内部表现未达目标，尤其 coding；Flash 已先上。对照 xAI 开源 Grok Build：终端 coding agent，含 runtime、工具调用与 TUI。

一边因质量门槛放慢旗舰，一边把 agent 工作流继续往下沉——节奏不同，但都在回答同一问题：谁更可靠地帮人把事做完。

06

TAKE

我怎么看

不是新闻，是判断

AI 竞争中心，正在从“单点模型智能”扩成三角结构——

模型层：谁以更开放、更便宜的方式顶到前排
规则层：谁组织治理与合作网络
身体层：谁把智能装进通话、机器人与边缘设备

对普通人最实用的三层：

01长上下文 + 工具调用，会继续比“会不会聊天”更值钱。

02国行产品体验会越来越绑定本地模型与合规框架。

03机器人与实时交互仍有距离，但产业时间表已从概念变成里程碑年份。
